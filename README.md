# Safe Zone France — V1

Prototype mobile-first d'une carte communautaire de vigilance.

## Fonctionnalités
- Carte OpenStreetMap / Leaflet
- Géolocalisation
- Ajout d'un signalement par point sur la carte
- Catégories de vigilance
- Historique local des signalements
- Interface adaptée au téléphone

## Protection des personnes
Cette V1 n'est pas conçue pour publier des noms, adresses privées, photos de personnes ou accusations nominatives. Avant une mise en ligne communautaire, il faudra ajouter authentification, modération, signalement d'abus, règles de preuve et protection des données.

## Tester
Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche `main`.
